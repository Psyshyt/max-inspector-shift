# MAX Inspector Shift

Бот MAX для контроля смен пеших инспекторов и фиксации автомобилей с нарушениями ГРЗ.

## v0.1.0

Первая рабочая версия.

### Реализовано

- первый вход через `/start` или событие `bot_started`;
- приветствие и краткая инструкция;
- кнопка `🟢 Начать смену`;
- несколько смен в один день разрешены;
- сообщение о старте смены в отчётный чат;
- кнопка `📹 Зафиксировать нарушение`;
- ожидание видео только после явного начала фиксации;
- классификация видео:
  - `🔒 Закрыт ГРЗ`;
  - `🚫 Без ГРЗ`;
- отмена ошибочной фиксации;
- текущая статистика по смене;
- подтверждение перед завершением;
- итоговый подсчёт при закрытии смены;
- итоговый отчёт инспектору и в общий чат;
- сохранение состояния в `data/store.json`;
- открытые смены сохраняются после перезапуска контейнера;
- защита от повторной обработки callback и сообщений с видео;
- проверка `X-Max-Bot-Api-Secret`;
- endpoint `/health`;
- отдельный скрипт регистрации webhook.

Google Sheets намеренно не подключены в `v0.1.0`. Их можно добавить следующим релизом без изменения основной логики смен.

## Переменные окружения

Создать `.env` по примеру `.env.example`:

```env
BOT_TOKEN=...
WEBHOOK_SECRET=...
WEBHOOK_URL=https://your-domain.ru/webhook
REPORT_CHAT_ID=...
PORT=3000
TZ=Europe/Moscow
STORE_PATH=/app/data/store.json
```

`REPORT_CHAT_ID` на первом запуске можно оставить пустым. Бот будет работать, но отчёты в общий чат отправляться не будут.

## Docker

Сборка:

```bash
docker build -t YOUR_DOCKERHUB_LOGIN/max-inspector-shift:0.1.0 .
```

Публикация:

```bash
docker push YOUR_DOCKERHUB_LOGIN/max-inspector-shift:0.1.0
```

Запуск на сервере:

```bash
docker run -d \
  --name max-inspector-shift \
  --restart unless-stopped \
  --env-file /opt/max-inspector-shift/.env \
  -p 127.0.0.1:3010:3000 \
  -v /opt/max-inspector-shift/data:/app/data \
  YOUR_DOCKERHUB_LOGIN/max-inspector-shift:0.1.0
```

После этого nginx должен проксировать внешний HTTPS endpoint `/webhook` на `http://127.0.0.1:3010/webhook`.

## Регистрация webhook

После заполнения `.env`:

```bash
npm run webhook:setup
```

Подписка создаётся на события:

- `bot_started`
- `message_created`
- `message_callback`
- `bot_added`

## Как работает инспектор

1. Один раз открывает бота и нажимает `/start`/Start.
2. Нажимает `🟢 Начать смену`.
3. Для нарушения нажимает `📹 Зафиксировать нарушение`.
4. Отправляет видео.
5. Выбирает `🔒 Закрыт ГРЗ` или `🚫 Без ГРЗ`.
6. Повторяет для следующих автомобилей.
7. Нажимает `🔴 Завершить смену`.
8. Подтверждает завершение.
9. Бот отправляет итоговую статистику.

## Важно по данным

Видео в `v0.1.0` не скачиваются на сервер. В хранилище сохраняется ссылка/идентификатор исходного сообщения и доступные MAX-метаданные вложения. Это не раздувает диск сервера и оставляет возможность позже связать каждую запись с таблицей.
